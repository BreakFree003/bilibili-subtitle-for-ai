# Bilibili Subtitle for AI (Gemini 侧边栏助手)

这是一个极其轻量且无感的 Tampermonkey (油猴) 脚本，专门为配合 Chrome 侧边栏的 AI 大模型（如 Gemini、Claude 等）设计。

## ✨ 核心功能
当你打开 B 站视频页面时，本脚本会在后台静默抓取当前视频的完整字幕，并将其格式化为一段纯文本。
为了不干扰你正常观看视频，这段字幕被放置在一个**折叠的面板**中，位置紧贴在视频播放器下方、视频简介上方。

- **0 视觉干扰**：默认只显示一行可点击的提示文本，不破坏 B 站原有界面结构。
- **专为 AI 读取优化**：文本加上了明确的 Prompt 前缀（`==== 视频完整字幕文本（供AI总结使用） ====`），Chrome 侧边栏的 AI 工具可以直接通过读取网页结构获取这段文本。
- **分P自动适配**：如果当前视频有多个分P（如 P1, P2），脚本会自动侦测页面变化并拉取对应的字幕。
- **纯净本地运行**：只向 B 站官方接口请求数据，包含 Wbi 签名算法，无任何第三方追踪或中转。

## 🚀 安装方法
1. 首先，你需要安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)。
2. 在此仓库中打开 `bilibili-subtitle.user.js` 文件，点击右上角的 **Raw** 按钮，油猴插件将会自动识别并提示安装。

## 💡 使用场景
1. 打开任意带有字幕的 B 站视频。
2. 呼出 Chrome 浏览器的侧边栏（选择 Gemini）。
3. 直接向大模型发送对话：“总结一下当前页面的视频内容”、“提取一下视频里的核心观点”。
4. 侧边栏 AI 会瞬间读取到折叠面板里的精准字幕文本，并给出高质量的回答。再也不用对着两小时的视频苦苦记笔记了！
